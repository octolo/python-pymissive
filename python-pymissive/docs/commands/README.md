# CLI Commands documentation

Command help is available via `--help`:

```bash
pymissive --help            # Shows README.md
pymissive missive --help    # Shows docs/commands/missive.md
pymissive attachment --help # Shows docs/commands/attachment.md
pymissive recipient --help # Shows docs/commands/recipient.md
pymissive billing --help    # Shows docs/commands/billing.md
pymissive webhook --help    # Shows docs/commands/webhook.md
```

These markdown files are the source for the in-app help. A copy is bundled in `pymissive/commands/_docs/` for installed packages.
